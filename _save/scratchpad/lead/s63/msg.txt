A setup page on the first start, and the hand-built world's roads compile into world.bin

The first start (the user's PC session; src/ui/menus.cpp, hud.h, src/game/app.cpp, src/platform/updater.*):
- A player's very first start, with no settings.ini in the data folder and not a test run, opens a setup page,
  "WELCOME TO PALMERA", before the main menu.
- Its rows: display (fullscreen or windowed), graphics quality (Low to Ultra), master volume, subtitles, automatic
  updates, and "Start playing".
  - Each change applies at once.
  - Start or Esc ("Skip") saves settings.ini and opens the main menu, so the page shows once.
  - Keyboard, mouse and gamepad all work.
- Players with a settings.ini, and every automated run (Updater::isAutomatedRun(): --autotest, --shot, --autoplay,
  --benchmark, --menushot and the rest), go straight to the main menu as before.
- Checks (PC worker): the MSVC build passes with no warnings, and a first start with an empty data folder opened the
  page. Closing the window on the page left no settings.ini.

The hand-built world's roads (city; src/world/roadsbin.*, handworld.*, tools/worldc.cpp, src/main.cpp, build.sh,
docs/NTW_FORMAT.md, docs/HANDBUILT_WORLD.md, tests/world/worldmodel_test.cpp, src/world/roomlight.h):
- worldc compiles world, district, roads, signal and transit files through the world model into world.bin's "roads"
  section (version 1: nodes, edges, classes, lanes, widths, cut-backs, seeds, names, points) and its "roads.ids"
  section (every node's and edge's authored id, for missions, saves and tools).
- Blocks, buildings, places and the library stop the build with "no compiler for X files yet", until their compilers
  exist.
- --world=hand reads the roads into the game's road network, or an empty network when world.bin has none.
  - readRoads refuses a missing, truncated, over-long, inconsistent or other-version section with a reason, and never
    leaves half a network.
  - world/ has only the terrain today, so the embedded world.bin is byte-identical to before.
- roomlight.h gains roomMinute(timeOfDay), which the shader side shares.
- worldmodel_test: an exact round trip (every field, the ids, the spatial hash after the read), an empty network, a
  network without ids, six damaged sections, and roomMinute.
- Checks (city): worldmodel_test with CI's flags; worldc on world/ identical to before; a test world's roads read back
  identical to compileRoads on its files; hand mode with and without roads; and a procedural drive smoke.

The PC worker (lead; docs/PC_WORKER.md), from its packages on the user's PC:
- Game paths go unquoted, because `"...\"` swallows the next argument (--datadir) on Windows, with NEONTIDE_DATADIR as a
  fallback and a muted game.
- Shots are saved as JPEG.
- Keys are held for 200 ms.
- Window shots are DPI-aware and taken after Init done.

Checks (lead, on this tree): CI's six GCC steps pass with its flags (-Wall -Wextra -Werror, UBSan). Then the snapshot
smoke: the -O2 build, the 150 shaders, and the drive and melee autoplays.
