HOW
- buildings.h:
  - Building::use, a BuildingUse: BU_DEFAULT (as its style says) or BU_PARKING. This is needed because BS_GARAGE is also the style of blockstyle.cpp's 3,450 back buildings (back houses, lock-up garages, sheds), which use it so that gameplay leaves them alone. The AI can now tell a parking garage by b.use == BU_PARKING.
  - kFacadeParking = 32, a new FacadeGPU flag bit, with the bits documented.
- buildings.cpp: both BS_GARAGE facade builders (the street generator's, and addSiteBuilding's for the site garages) set b.use = BU_PARKING and flags |= kFacadeParking. The back buildings build their own facades in blockstyle.cpp, so they stay unflagged.
- facade.hlsli: facadeRoomSchedule() takes the flag and returns kRoomAlways for a garage. That is the existing all-night class of stairwells and lobbies, which is never vacant (the litFrac draw skips kRoomAlways). This is 3 code lines: no new schedule, and no roomlight.h or table change.
